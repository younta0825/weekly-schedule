# 주간 근무표

매장 사장님이 직원들의 주간 근무표를 쉽게 짜고 공유할 수 있는 웹 도구예요. 설치 없이 브라우저에서 바로 쓸 수 있어요.

**👉 바로 써보기: https://younta0825.github.io/weekly-schedule/

## 주요 기능
- **근무표 편집**: 칸을 눌러 출근/휴무를 지정하고, 직원이 못 나오는 날은 "근무 불가"로 표시
- **자동 배치**: 요일별 필요 인원과 직원별 주 근무일수를 맞춰 빈칸을 자동으로 채움
  - 후보가 가장 적은 날부터 채우고, 고를 수 있는 날이 적은 직원을 우선 배치
  - 연속 근무가 길어지지 않도록 조정, 다시 누르면 다른 조합 제시
  - 직접 지정한 출근은 자동 배치를 다시 해도 유지
- **검증**: 인원 부족·초과, 근무일수 미달·초과를 바로 경고
- **공유**: 이미지(PNG) 저장, 카톡용 텍스트 복사, 인쇄/PDF
- **관리**: 직원 추가·순서 변경·퇴사 처리, 지난주 근무 복사, 주 시작 요일(월/일) 선택
- **저장**: 데이터는 브라우저(localStorage)에 저장, JSON 파일로 백업·복원

## 기술
- HTML, CSS, JavaScript 한 파일 (외부 라이브러리 없음, 오프라인 동작)
- 날짜 단위 데이터 구조로 주 시작 요일을 바꿔도 기록이 어긋나지 않음 (이전 형식 자동 변환 포함)
- 이미지 저장은 Canvas로 직접 그려서 구현
